# Лабораторная работа №2 - Серверные классы

## 📋 Описание проекта
Веб-приложение для перевода слов с русского на английский и обратно.

## 🏗️ Архитектура
- **Сервер**: Java Servlet + MySQL + Apache Tomcat
- **Клиент**: Java Swing приложение
- **База данных**: MySQL с таблицей переводов

## ⚙️ Функциональность
- ✅ Перевод слов (русский ↔ английский)
- ✅ Веб-интерфейс
- ✅ Desktop клиент
- ✅ Генерация Word отчетов
- ✅ Работа с базой данных

## 🚀 Запуск проекта

### Серверная часть
```bash
cd server
mvn clean package
# Развернуть WAR на Tomcat
```
### Клиентская часть
```bash
cd client
mvn clean compile exec:java
```
🛠️ Технологии
Java 11+

- **Apache Tomcat 9**
- **MySQL 8.0**
- **Apache POI (Word документы)**
- **Java HTTP Client**
